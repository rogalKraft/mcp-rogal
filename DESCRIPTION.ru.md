# MCP-rogal

**MCP-сервер для разработки модов и датапаков под Minecraft.**

Направь ИИ-ассистента на запущенную игру — и он напишет датапак, перезагрузит его, выполнит,
прочитает ошибку, которую игра действительно выдала, и починит. Без пересказа руками.

26 инструментов, Fabric, Minecraft 26.3.

---

## Идея

Больше всего времени при написании датапака уходит на одно: что-то не сработало, а игра не
говорит почему. Макрос без одного `$(key)` обрывает функцию целиком. `/reload` рапортует
успех, хотя пак, который он только что пытался загрузить, упал. Разоружённый триггер выглядит
точно как кнопка, которая просто ничего не делает.

Поэтому каждая команда возвращает то, что произошло на самом деле:

```
time set day                            → success=true    result=1000
setblock ~ ~ ~ minecraft:not_a_block    → errorType=parse  cursor=15
execute if block ~ ~ ~ bedrock run say  → success=false    error=null
```

Три разных исхода, и они различимы: сработало и вернуло 1000; не разобралось, вот символ, на
котором разбор встал; отработало нормально и не сделало ничего.

Последняя строка — самая важная. Так выглядит тихий отказ, и теперь он виден, а не сливается
с успехом.

## Что умеет

### Команды и время
- **`execute_commands`** — настоящий статус, возвращаемое значение, ошибки разбора с позицией
  курсора. `run_as: {player, permission_level}` выполняет с выбранным уровнем прав: `execute as X`
  меняет `@s`, но оставляет *твои* права, поэтому оператор-онли путь выглядит рабочим ровно до
  того момента, как на него попадёт обычный игрок. Здесь проверяется именно его путь.
- **`advance_ticks`** и аргумент `wait_ticks` — записанное в этом тике не видно чтению до
  следующего, так что пара «запись + чтение» в одном вызове молча читает старое значение.
- **`validate_command`** — разбор без выполнения, плюс автодополнение в позиции курсора: так
  узнают, что вообще принимает аргумент.

### Логи
- **`get_logs`** — курсорный. В ответе есть `nextId`; передай его обратно и получишь только
  новое. Сообщает `missed`, если буфер переполнился за твоим курсором — пропуск виден, а не
  молчалив. Покрывает и файл лога, и внутриигровой чат, который в файл не попадает вовсе.
- **`wait_for_log`** — блокируется до появления совпадения. Запусти что-то и жди строку, которая
  скажет, сработало ли, вместо опроса в цикле.
- **`get_crash_reports`** — когда игра умерла вместе с буфером.

### Датапаки
- **`files`** — чтение, запись, список; строго внутри белого списка директорий.
- **`reload_datapacks`** — выполняет `/reload` и возвращает лог, который тот породил, потому что
  `/reload` успешен даже когда пак не загрузился.
- **`get_world_info`** — папка сохранения, папка датапаков и **форматы паков этой сборки**.
  Неверный `pack_format` — пак отклонён с одной невнятной строкой «Error reading pack metadata»,
  а каждая функция внутри тихо не работает.
- **`list_ids`**, **`describe_block_state`** — валидные ID по реестрам и точные свойства блока
  для `[скобок]` с допустимыми значениями и умолчаниями. Больше не надо гадать, у двери
  `half=upper` или `part=head`.

### Фейковые игроки
**`fake_players`** — настоящие `ServerPlayer` в списке игроков, для правил, которые существуют
только когда игроков больше одного. `@a` их выбирает, скорборд считает, UUID выводится из имени,
поэтому счёт переживает смерть, после `kill` они возрождаются, `despawn` даёт настоящее событие
выхода, `/tp` переносит между измерениями.

Нигде в игровой логике нет проверки «это фейк — пропустить»: тест против специально обойдённого
кода ничего не доказывает про настоящий.

Чего не умеют: нажать кнопку в диалоге — для этого нужен клиент.

### Управление клиентом
- **`press_key`**, **`type_text`**, **`send_keybind`**, **`mouse`** — ввод идёт через те же точки,
  что и настоящий, поэтому ведёт себя одинаково в мире, в меню и в текстовых полях.
- **`get_open_screen`** — каждый виджет с **отрисованным текстом** и прямоугольником. Смотреть
  меню без чтения скриншота; отсутствующие переводы видно сразу, потому что непереведённый виджет
  рисует свой сырой ключ.
- **`click_widget`** — клик по видимой надписи кнопки. Неоднозначное совпадение не кликает ничего
  и возвращает кандидатов. Надписи вроде «Удалить мир» отклоняются без явного разрешения.
- **`open_screen`**, **`options`** — сразу нужный экран или смена настройки без таскания слайдера.
- **`reload_resources`** — это F3+T, которого нет в командах.
- **`rejoin_world`** — динамические реестры (`dialog/`, `enchantment/`, `worldgen/`) читаются
  только при загрузке мира. `/reload` оставляет старые определения, и это выглядит ровно как
  «правка не подействовала».

## Установка

**Требуется:** Minecraft 26.3 · Fabric Loader 0.19.5+ · Fabric API · Java 25+

1. Поставь [Fabric Loader](https://fabricmc.net/use/installer/) под 26.3
2. Положи [Fabric API](https://modrinth.com/mod/fabric-api) в `mods/`
3. Положи туда же jar этого мода
4. Запусти игру

Сервер поднимается сам и пишет в лог:

```
HTTP MCP Server started on http://localhost:8080/mcp with 26 tools
```

Работает и на клиенте, и на выделенном сервере. На выделенном инструменты, которым нужен экран,
просто не регистрируются.

### Подключение ассистента

Эндпоинт — обычный streamable HTTP, поэтому его принимает любой MCP-клиент. Добавь его в
конфигурацию MCP своего клиента:

```json
{
  "mcpServers": {
    "minecraft": {
      "url": "http://localhost:8080/mcp"
    }
  }
}
```

Клиенты, которые настраиваются из командной строки, обычно принимают то же самое: транспорт
http и URL.

Мир должен быть загружен. Без него инструменты честно об этом скажут.

## Как это выглядит

**Цикл датапака целиком, без выхода из игры:**
> Напиши функцию, которая выдаёт компас всем хантерам, положи в датапак, перезагрузи и скажи,
> загрузилась ли она.

`get_world_info` (папка и формат пака) → `files write` → `reload_datapacks` → чтение лога. Пак,
который не загрузился, будет назван, а не проигнорирован.

**Проверка неоператорского пути:**
> Проверь, что `/dialog show` недоступен обычному игроку, а через `/trigger` работает.

`execute_commands` с `run_as: {permission_level: 0}`.

**Многопользовательское правило:**
> Подними двух фейков, раздай роли и проверь, что у каждого хантера свой компас.

**Навигация по меню:**
> Открой настройки графики и скажи, что там стоит.

`open_screen`, затем `get_open_screen` вернёт текст каждого виджета.

## Настройка

`config/mcp.json`, создаётся при первом запуске:

```jsonc
{
  "server": { "port": 8080, "host": "localhost", "requestTimeoutMs": 30000 },
  "input":  { "enabled": true, "allowDestructiveUi": false,
              "preventPauseOnLostFocus": true },
  "logs":   { "bufferSize": 5000, "maxWaitMs": 60000, "maxBodyLogChars": 2000 },
  "files":  { "enabled": true, "allowDelete": false,
              "allowedRoots": ["saves","config","datapacks","resourcepacks",
                               "logs","crash-reports"] },
  "fakePlayers": { "enabled": true, "maxCount": 8 },
  "auth":   { "token": null }
}
```

**`preventPauseOnLostFocus`** — одиночная игра обычно встаёт на паузу, стоит переключиться в
другое окно, и меню паузы закрывает вид. Тогда каждый скриншот и каждое чтение экрана возвращали
бы меню паузы вместо игры. Здесь это выключено по умолчанию; Escape по-прежнему ставит паузу.

## Безопасность

Этот эндпоинт выполняет команды, инжектит ввод и пишет файлы. Отнесись соответственно.

- **`auth.token`** — если задан, требуется заголовок `Authorization: Bearer <token>`.
- **Сервер откажется стартовать** на не-loopback адресе без токена.
- **Файлы** — только внутри белого списка; пути, уходящие наружу через `..` или симлинк,
  отклоняются. Удаление выключено по умолчанию.
- **Разрушительные кнопки** — клик по «Удалить мир» и подобным требует и флага в конфиге, и
  явного аргумента.
- Команды по-прежнему проходят настраиваемый валидатор безопасности.

## Технические детали

- Ввод идёт через приватные callback-точки `KeyboardHandler` и `MouseHandler` (миксин-инвокеры),
  а не через `KeyMapping` — поэтому работает в меню и текстовых полях, а не только в мире.
- Команды исполняются на серверном потоке через `CommandSourceStack.withCallback`, ошибки разбора
  отделены от ошибок исполнения. В одиночной игре это встроенный сервер, поэтому результат
  настоящий, а не выведенный из чата.
- Логи собирает Log4j-аппендер, подключаемый программно, с защитой от реентрантности.
- Инструменты живут в реестре — добавить свой это один класс.
- Всё касание загрузчика вынесено за интерфейс `Platform`, поэтому порт на NeoForge — это точка
  входа, подписка на тик и конфиг миксинов; остальное ванильный API Minecraft.

## Если что-то не так

**Не подключается** — ищи `HTTP MCP Server started` в логе. Порт 8080 может быть занят, поменяй
`server.port`.

**«No server is running»** — мир не загружен.

**Команда вернула `success=false` без ошибки** — она отработала и ничего не сделала. Обычно
условие не совпало или функция вышла раньше. Это не сбой инструмента.

**`/function` всегда `success=false`** — так устроена ваниль: функция возвращает 0, если не
заканчивается на `/return`. Проверяй состояние мира или добавь `/return`.

**Датапак не подхватывается** — сверь `pack_format` через `get_world_info`.

**Правка не действует после `/reload`** — если это `dialog/`, `enchantment/` или `worldgen/`,
нужен `rejoin_world`.

**Клик не сработал** — экраны с затуханием переключаются на несколько тиков позже. Подними
`settle_ticks` или перечитай `get_open_screen`.
